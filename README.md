# Selection-des-variables-en-grande-dimension-en-analyse-de-survie-avec-evenements-concurrents

L'objectif est de trouver une méthode de selection des variables en grande dimension pour l'analyse de survie avec risque concurrents. 

Presenter la methode CooPer(Cooperative Penalization regression)

# Objectifs

# Contexte du projet

Ce projet a été présenté lors d'une candidature de thèse en mathématiques appliquées et biostatistique, en septembre 2026

# Ce que fait le projet

- Présenter la méthode Coopérative Penalized regression
- Etude de simulation en comparant la méthode avec d'autres méthodes
- Application aux données réelles : Données de cancer de vessie
